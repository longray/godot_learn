# 第 6 课：玩家攻击、敌人生命值、敌人死亡掉落

本课目标：

1. 给玩家添加攻击能力。
2. 攻击使用一个短暂存在的 `Area2D`。
3. 敌人拥有生命值。
4. 敌人被攻击后会闪烁。
5. 敌人死亡后从地图中移除。
6. 敌人死亡后有概率掉落物品。
7. 掉落物可以是金币或药水。
8. 药水可以恢复玩家生命。

# 1. 本课战斗设计

为了保持简单，本课使用一种非常经典的 2D 动作原型方案：

```text
玩家按下攻击键
在玩家朝向位置生成一个短暂攻击区域
攻击区域碰到敌人
敌人掉血
```

攻击区域不是永久节点，而是：

```text
生成
存在 0.08 秒左右
销毁
```

这样可以避免复杂的攻击状态机。

后续你可以把它升级为：

- 武器贴图。
- 攻击动画。
- 攻击连段。
- 攻击冷却。
- 暴击。
- 击退。
- 弓箭/子弹。
- 技能系统。

# 3. 更新 Player 脚本

打开：

```text
player.gd
```

我们将它升级成支持攻击和治疗的版本。

完整替换为下面代码：

```gdscript
extends CharacterBody2D

# 第 6 课：可攻击、可受伤、可治疗的玩家

@export var speed: float = 140.0
@export var collision_radius: float = 5.0

@export var max_health: int = 3
@export var invincibility_time: float = 0.8

@export var attack_damage: int = 1
@export var attack_cooldown: float = 0.35
@export var attack_duration: float = 0.08
@export var attack_radius: float = 12.0
@export var attack_offset: float = 16.0

# 默认使用 ui_accept，也就是空格/回车
# 后续可以改成自定义动作，例如 "attack"
const ATTACK_ACTION := "ui_accept"

var dungeon: Node

var health: int = 3
var invincible: bool = false
var knockback := Vector2.ZERO

var facing := Vector2.RIGHT
var attack_cooldown_remaining: float = 0.0


func _ready() -> void:
    health = max_health


func reset_for_new_layer() -> void:
    health = max_health
    invincible = false
    knockback = Vector2.ZERO
    modulate.a = 1.0


func heal(amount: int) -> void:
    health = mini(max_health, health + amount)
    print("恢复生命，当前生命：", health)


func _physics_process(delta: float) -> void:
    if dungeon == null or not dungeon.has_method("is_world_position_walkable"):
        velocity = Vector2.ZERO
        move_and_slide()
        return

    var input_vector := Input.get_vector(
        "ui_left",
        "ui_right",
        "ui_up",
        "ui_down"
    )

    var desired_velocity := Vector2.ZERO

    if input_vector != Vector2.ZERO:
        desired_velocity = input_vector.normalized() * speed
        facing = desired_velocity.normalized()

    # 攻击冷却
    attack_cooldown_remaining = maxf(0.0, attack_cooldown_remaining - delta)

    if Input.is_action_just_pressed(ATTACK_ACTION) and attack_cooldown_remaining <= 0.0:
        _attack()

    var move_velocity := desired_velocity + knockback

    # 击退随时间衰减
    knockback = knockback.move_toward(Vector2.ZERO, 500.0 * delta)

    if move_velocity == Vector2.ZERO:
        velocity = Vector2.ZERO
        move_and_slide()
        return

    var next_position := global_position + move_velocity * delta

    if dungeon.is_world_position_walkable(next_position, collision_radius):
        velocity = move_velocity
    else:
        var x_only_position := Vector2(next_position.x, global_position.y)
        var y_only_position := Vector2(global_position.x, next_position.y)

        if dungeon.is_world_position_walkable(x_only_position, collision_radius):
            velocity = Vector2(move_velocity.x, 0.0)
        elif dungeon.is_world_position_walkable(y_only_position, collision_radius):
            velocity = Vector2(0.0, move_velocity.y)
        else:
            velocity = Vector2.ZERO

    move_and_slide()


func take_damage(amount: int, source_position: Vector2) -> void:
    if invincible:
        return

    health -= amount

    print("玩家受伤，剩余生命：", health)

    if health <= 0:
        die()
        return

    _apply_knockback(source_position)
    _start_invincibility(invincibility_time)


func die() -> void:
    print("玩家死亡，回到入口。")

    health = max_health
    knockback = Vector2.ZERO

    if dungeon and dungeon.has_method("respawn_player"):
        dungeon.respawn_player()

    _start_invincibility(invincibility_time * 1.5)


func _apply_knockback(source_position: Vector2) -> void:
    var direction := global_position - source_position

    if direction == Vector2.ZERO:
        direction = Vector2.RIGHT

    knockback = direction.normalized() * 180.0


func _start_invincibility(duration: float) -> void:
    invincible = true
    modulate.a = 0.45

    await get_tree().create_timer(duration).timeout

    if is_inside_tree():
        invincible = false
        modulate.a = 1.0


func _attack() -> void:
    attack_cooldown_remaining = attack_cooldown

    var hitbox := Area2D.new()

    # 攻击区域只检测敌人 Layer
    # 我们在第 5 课建议敌人根节点使用 Layer 2
    hitbox.collision_layer = 0
    hitbox.collision_mask = 2

    hitbox.position = facing * attack_offset

    var collision := CollisionShape2D.new()
    var circle := CircleShape2D.new()
    circle.radius = attack_radius
    collision.shape = circle
    hitbox.add_child(collision)

    # 简单攻击可视化
    var visual := Polygon2D.new()
    var size := attack_radius * 0.8

    visual.polygon = PackedVector2Array([
        Vector2(-size, -size),
        Vector2(size, -size),
        Vector2(size, size),
        Vector2(-size, size)
    ])

    visual.color = Color(1.0, 1.0, 1.0, 0.35)
    hitbox.add_child(visual)

    hitbox.body_entered.connect(_on_attack_hitbox_body_entered.bind(hitbox))

    add_child(hitbox)

    await get_tree().create_timer(attack_duration).timeout

    if is_instance_valid(hitbox):
        hitbox.queue_free()


func _on_attack_hitbox_body_entered(body: Node2D, hitbox: Area2D) -> void:
    if body.has_method("take_damage"):
        body.take_damage(attack_damage, global_position)
```

# 4. 更新 Enemy 脚本

打开：

```text
enemy.gd
```

我们将它升级成有生命值、受击、死亡、掉落的版本。

完整替换为：

```gdscript
extends CharacterBody2D

# 第 6 课：有生命值、会死亡的巡逻敌人

@export var speed: float = 70.0
@export var wait_time: float = 0.8
@export var arrival_distance: float = 4.0
@export var collision_radius: float = 4.0
@export var contact_damage: int = 1

@export var max_health: int = 2

var dungeon: Node
var patrol_points: Array = []

var current_point_index: int = 0
var is_waiting: bool = false
var wait_remaining: float = 0.0

var health: int = 2
var dead: bool = false

@onready var hitbox: Area2D = $Hitbox


func _ready() -> void:
    health = max_health

    if hitbox:
        hitbox.body_entered.connect(_on_hitbox_body_entered)


func setup(dungeon_reference: Node, points: Array) -> void:
    dungeon = dungeon_reference
    patrol_points = points

    health = max_health
    dead = false

    if patrol_points.is_empty():
        return

    global_position = patrol_points[0]
    current_point_index = 0

    if patrol_points.size() > 1:
        current_point_index = 1

    is_waiting = false
    wait_remaining = 0.0


func take_damage(amount: int, source_position: Vector2 = Vector2.ZERO) -> void:
    if dead:
        return

    health -= amount

    print("敌人受击，剩余生命：", health)

    if health <= 0:
        dead = true
        _die()
        return

    _flash()


func _die() -> void:
    if dungeon and dungeon.has_method("on_enemy_died"):
        dungeon.on_enemy_died(self, global_position)

    queue_free()


func _flash() -> void:
    modulate = Color(1.0, 0.4, 0.4)

    await get_tree().create_timer(0.08).timeout

    if is_inside_tree() and not dead:
        modulate = Color.WHITE


func _physics_process(delta: float) -> void:
    if dead:
        velocity = Vector2.ZERO
        move_and_slide()
        return

    if dungeon == null or not dungeon.has_method("is_world_position_walkable"):
        velocity = Vector2.ZERO
        move_and_slide()
        return

    if patrol_points.is_empty():
        velocity = Vector2.ZERO
        move_and_slide()
        return

    if patrol_points.size() == 1:
        velocity = Vector2.ZERO
        move_and_slide()
        return

    if is_waiting:
        wait_remaining -= delta
        velocity = Vector2.ZERO

        if wait_remaining <= 0.0:
            is_waiting = false
            current_point_index = (current_point_index + 1) % patrol_points.size()

        move_and_slide()
        return

    var target: Vector2 = patrol_points[current_point_index]
    var direction: Vector2 = target - global_position
    var distance: float = direction.length()

    if distance <= arrival_distance:
        is_waiting = true
        wait_remaining = wait_time
        velocity = Vector2.ZERO
        move_and_slide()
        return

    var desired_velocity := direction.normalized() * speed
    var next_position := global_position + desired_velocity * delta

    if dungeon.is_world_position_walkable(next_position, collision_radius):
        velocity = desired_velocity
    else:
        velocity = Vector2.ZERO
        current_point_index = (current_point_index + 1) % patrol_points.size()

    move_and_slide()


func _on_hitbox_body_entered(body: Node2D) -> void:
    if dead:
        return

    if body.is_in_group("player") and body.has_method("take_damage"):
        body.take_damage(contact_damage, global_position)
```

## 5.5 添加掉落物生成函数

添加：

```gdscript
func _spawn_drop_at_position(world_position: Vector2) -> void:
    var drop_type := "gold"

    if rng.randf() < enemy_potion_chance:
        drop_type = "potion"

    _create_drop_area(drop_type, world_position)


func _create_drop_area(drop_type: String, world_position: Vector2) -> Area2D:
    var area := Area2D.new()

    area.monitoring = true
    area.collision_layer = 0
    area.collision_mask = 1

    var collision := CollisionShape2D.new()
    var circle := CircleShape2D.new()
    circle.radius = cell_size * 0.25
    collision.shape = circle
    area.add_child(collision)

    var visual := Polygon2D.new()
    var size := cell_size * 0.25

    visual.polygon = PackedVector2Array([
        Vector2(-size, -size),
        Vector2(size, -size),
        Vector2(size, size),
        Vector2(-size, size)
    ])

    if drop_type == "gold":
        visual.color = Color(1.0, 0.9, 0.25)
    else:
        visual.color = Color(0.3, 0.9, 0.9)

    area.add_child(visual)

    area.add_to_group("drop")
    area.body_entered.connect(_on_drop_body_entered.bind(area, drop_type))

    add_child(area)
    area.global_position = world_position

    dynamic_entities.append(area)

    return area
```

# 6. 检查敌人碰撞层

这一课非常重要的一点是：

> 玩家攻击区域必须能检测到敌人。

我们在第 5 课建议：

```text
Enemy 根节点 Collision Layer = 2
Enemy 根节点 Collision Mask = 0
```

本课玩家攻击区域设置为：

```gdscript
hitbox.collision_layer = 0

```

所以：

```text
攻击区域只检测 Layer 2 的敌人。
```

如果你的敌人根节点不在 Layer 2，攻击会打不到敌人。

# 8. 本课核心知识讲解

---

## 8.1 为什么攻击区域是临时生成的？

本课攻击采用：

```text
按下攻击键
生成 Area2D
短暂存在
销毁
```

这样做的好处：

- 不需要复杂的攻击动画状态机。
- 不需要永久维护攻击节点。
- 攻击范围跟随当前朝向。
- 容易扩展不同武器。

例如以后可以做：

```text
短剑：小范围，短冷却
长剑：前方矩形
斧头：大范围，慢冷却
弓箭：发射投射物
法术：圆形范围爆炸
```

---

## 8.2 为什么攻击区域使用 collision_mask = 2？

因为我们将敌人根节点放在：

```text
Layer 2
```

玩家攻击区域设置：

```text
Mask 2
```

所以攻击区域只会检测敌人，不会检测玩家、掉落物、出口。

这是 Godot 物理层非常典型的用法：

```text
Layer 1：玩家
Layer 2：敌人
Layer 3：道具
Layer 4：陷阱
Layer 5：投射物
```

后续项目越大，越需要规划碰撞层。

---

## 8.3 敌人死亡为什么通过 Main 处理掉落？

敌人死亡时调用：

```gdscript
dungeon.on_enemy_died(self, global_position)
```

然后由 `Main` 决定：

```text
是否掉落
掉落什么
掉落物节点如何生成
掉落物是否加入当前层动态实体
```

这样做的好处是：

```text
敌人只负责自己的死亡。
地图/关卡负责内容和规则。
```

这非常适合 RPG 程序化地图。

后续你可以让不同敌人掉落不同物品：

```text
小怪掉金币
精英掉药水
Boss 掉钥匙
远程怪掉箭
```

---

## 8.4 为什么金币跨层保留？

当前代码中：

```gdscript
gold_count
```

没有在 `generate()` 里重置。

因此金币会跨层保留。

这更符合传统 RPG：

```text
金币是玩家长期资源。
钥匙、宝箱、敌人通常每层重置。
```

当然你也可以做成：

```text
死亡清空金币
死亡掉落一半金币
进入下一层保留金币
回到入口清空临时状态
```

# 9. 常见问题排查

---

## 问题 1：攻击没有伤害

检查：

1. 敌人根节点是否设置了：

```text
Collision Layer = 2
```

2. 玩家攻击区域代码是否为：

```gdscript
hitbox.collision_mask = 2
```

3. 敌人脚本是否有：

```gdscript
func take_damage(...)
```

4. 敌人是否已经被死亡标记：

```gdscript
dead = true
```

5. 攻击区域是否真的出现在敌人附近。

---

## 问题 2：攻击区域出现了，但打不到敌人

最常见原因是碰撞层不对。

推荐设置：

```text
Player 根节点：
    Collision Layer = 1
    Collision Mask = 1

Enemy 根节点：
    Collision Layer = 2
    Collision Mask = 0

Enemy Hitbox：
    Collision Layer = 0
    Collision Mask = 1

玩家攻击 hitbox：
    Collision Layer = 0
    Collision Mask = 2
```

---

## 问题 3：敌人死亡后没有掉落

检查：

1. `enemy_drop_chance` 是否大于 0。
2. 控制台是否打印敌人死亡。
3. `Main` 是否有：

```gdscript
func on_enemy_died(...)
```

4. 敌人脚本 `_die()` 是否调用了：

```gdscript
dungeon.on_enemy_died(self, global_position)
```

---

## 问题 4：药水不回血

检查：

1. 玩家脚本是否有：

```gdscript
func heal(amount: int)
```

2. 掉落物回调是否调用了：

```gdscript
body.heal(1)
```

3. 玩家是否已经满血。

当前满血时也会拾取药水，但生命不会超过 `max_health`。

---

## 问题 5：攻击可以穿墙打怪

本课攻击没有做墙体遮挡检测。

也就是说：

```text
如果敌人就在墙后面，攻击仍可能命中。
```

这是简化处理。

后续可以加：

- 攻击前检测目标方向是否可走。
- 用射线检测墙壁。
- 用 `AStarGrid2D` 判断视线。
- 用物理射线 `Physics2DDirectSpaceState`。
