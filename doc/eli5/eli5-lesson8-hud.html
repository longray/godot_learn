📡 心形是怎么自己变的？——信号

❌ 以前：玩家直接喊 HUD（紧耦合）
# player.gd —— 玩家必须认识 dungeon
func take_damage(amount):
	health -= amount
	if dungeon.has_method("update_health_ui"):
		dungeon.update_health_ui(health, max_health)
✓ 现在：发信号广播（解耦）
signal health_changed(current, max)

func take_damage(amount):
	health -= amount
	health_changed.emit(health, max_health)
	# 谁在听？不关我的事～

就像从「挨个打电话通知」变成「发一条朋友圈」——想看的人自然能看到。

👾敌人全部刷新
🪙金币带走的战利品！
🏰层数 +1越挖越深…

红色 = 本层重新开始 · 绿色 = 永久保留 —— 经典 Roguelite 规则

💡 HUD = 游戏和玩家之间的「状态通信」。
玩家变状态 → 发信号 → HUD 自动刷新，三层各干各的，谁也不依赖谁。
