房间检测与小地图

给地牢装一块「商场导览图」——你走过哪里、身在何处、出口何方

第 9 课 · Godot 2D RPG 地牢

🏬 想象商场的导览图

商场图告诉你「您在此处」；小地图告诉你「你还有 3 个房间没逛」。
没走过的区域 = 黑暗，走过才点亮 —— 这就是探索感。

🔍 程序怎么知道你在哪个房间？

🔍 检测核心（每 0.1 秒跑一次，不用每帧）
# 世界坐标 → 格子 → 在哪个房间矩形里
var cell := Vector2i(
	floori(pos.x / 16.0), floori(pos.y / 16.0))
var idx := _find_room_index_containing_cell(cell)
# 命中 → 标记已探索 + 设为当前房间 → 小地图重绘
explored_rooms[idx] = true   # 字典查询 O(1)，飞快
